TypeScript Tips and Tricks for Better Code

TypeScript has become essential for modern JavaScript development. Here are some tips to help you write better TypeScript code.

1. Use Strict Mode

Always enable strict mode in your tsconfig.json:

1{ 2 "compilerOptions": { 3 "strict": true, 4 "noImplicitAny": true, 5 "strictNullChecks": true 6 } 7}

2. Leverage Type Inference

Let TypeScript do the work when possible:

1// ❌ Unnecessary type annotation 2const name: string = "John" 3 4// ✅ Let TypeScript infer 5const name = "John" // TypeScript knows it's a string

3. Use Discriminated Unions

Great for handling different states:

1type State = 2 | { status: "loading" } 3 | { status: "success"; data: User[] } 4 | { status: "error"; error: string } 5 6function handleState(state: State) { 7 switch (state.status) { 8 case "loading": 9 return <Spinner /> 10 case "success": 11 return <UserList users={state.data} /> 12 case "error": 13 return <Error message={state.error} /> 14 } 15}

4. Use satisfies for Better Inference

New in TypeScript 4.9+:

1const config = { 2 apiUrl: "https://api.example.com", 3 timeout: 5000, 4} satisfies Config 5 6// config.apiUrl is typed as the literal "https://api.example.com" 7// not just string!

5. Generic Constraints

Make your generics more specific:

1// ❌ Too loose 2function getProperty<T>(obj: T, key: string) { 3 return obj[key] // Error! 4} 5 6// ✅ Constrained properly 7function getProperty<T, K extends keyof T>(obj: T, key: K): T[K] { 8 return obj[key] 9}

6. Utility Types

Master the built-in utility types:

TypeDescription
Partial<T>Makes all properties optional
Required<T>Makes all properties required
Pick<T, K>Select specific properties
Omit<T, K>Remove specific properties
Record<K, V>Create object type with key-value pairs
1interface User { 2 id: number 3 name: string 4 email: string 5} 6 7type UserPreview = Pick<User, "id" | "name"> 8type UserWithoutEmail = Omit<User, "email"> 9type PartialUser = Partial<User>

7. Template Literal Types

Create precise string types:

1type HTTPMethod = "GET" | "POST" | "PUT" | "DELETE" 2type Route = `/${string}` 3type Endpoint = `${HTTPMethod} ${Route}` 4 5const endpoint: Endpoint = "GET /users" // ✅ 6const invalid: Endpoint = "FETCH /users" // ❌ Error

Conclusion

TypeScript is a powerful tool that catches errors before runtime. By using these patterns, you'll write safer, more maintainable code.
